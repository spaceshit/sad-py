# Changelog

## 0.1.0 — Unreleased

- Library-first Analyzer, public dataclasses and versioned JSON model.
- Tree-sitter JavaScript, TypeScript, JSX and TSX parsing with bounded AST caching.
- Symbolic strings, aliases, objects, destructuring, conditional value joins, modules, wrapper chains, closures and basic class clients.
- HTTP and protocol adapters, HTML forms, programmatic forms, source-map embedded sources and literal lazy imports.
- Offline Burp XML, normalized JSON, HAR, raw HTTP and directory imports; captured responses feed static analysis.
- Conservative static/observed correlation with original observations retained.
- Bounded scoped crawler, CLI and JSON/JSONL/CSV/table serialization.
- Structured incompleteness issues, isolated branch heaps, return unions, bounded loops/recursive summaries, live module bindings, path mappings and bound calls.
- Static bundle module tables, indexed/VLQ source maps, client state tracking and Connect wire descriptors.
- An offline labeled detection corpus, pinned upstream examples, property/fuzz tests, separate line/branch gates and cross-platform CI artifacts.
- Documented endpoint origins and captured-response discovery in the README.
- Canonical seed redirects, fair source shares of the global analysis budget, retained partial exports, configurable CLI analysis steps and explicit partial-result status.
- CI, typed package, wheel/sdist validation, draft releases and trusted PyPI publishing workflow.

This is an initial implementation with the coverage limits in docs/architecture.md. No public release has been made.
